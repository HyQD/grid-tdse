# Examples

The runnable examples mirror the corresponding `grid_tdse` source hierarchy:

- [`spherical`](spherical/) contains spherical-coordinate examples;
- [`spherical/one_radial`](spherical/one_radial/) contains one-radial
  calculations;
- [`spherical/two_radial`](spherical/two_radial/) contains two-radial atomic
  and non-Born--Oppenheimer diatomic calculations.

Run examples from the repository root so that the paths shown in their module
documentation and the project documentation work unchanged.
