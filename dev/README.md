# Development documents

This directory contains active implementation plans, design discussions, and
other developer-facing material that may change as the code evolves.

Use the repository directories as follows:

- `dev/` for implementation roadmaps and provisional design decisions;
- `docs/` for stable user-facing setup, interfaces, numerical methods, and
  theory;
- `benchmarks/` for reproducible benchmark programs, summarized performance
  reports, and machine-readable benchmark data.

Development plans should state their current status and completion criteria.
Move durable material into `docs/` once the corresponding implementation and
public interface have stabilized.
