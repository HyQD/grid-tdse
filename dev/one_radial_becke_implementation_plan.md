# Prototype Implementation Plan for `one_radial_becke`

## Purpose

This document specifies a prototype of a Becke-weighted, atom-centered,
spherical-harmonic FE-DVR representation. The first Hamiltonian application
is a clamped one-electron diatomic, but the partition, quadrature, and basis
interfaces should support an arbitrary number of centers at arbitrary
Cartesian positions from the outset.

The prototype should answer one numerical question before the design is
extended further:

> Does a two-center Becke-weighted FE-DVR basis reduce the angular basis size
> needed to represent the two electron-nuclear cusps enough to justify its
> overlap-conditioning and multicenter-quadrature costs?

The existing midpoint-centered implementation in
`grid_tdse.spherical.one_radial` remains the reference representation. The
prototype belongs in the sibling package
`grid_tdse.spherical.one_radial_becke`.

The nonlinear TDHF, TDKS, and TD-RASSCF orbital equations are outside the
scope of `grid-tdse`. Those methods belong in `tdmcscf` and may consume this
spatial representation after it has been validated.

## Prototype scope

The first Hamiltonian prototype is deliberately narrow:

- clamped nuclei on the molecular `z` axis;
- one dynamical electron;
- H2+ as the initial test, followed by a heteronuclear one-electron system;
- two atom-centered spherical expansions in the initial Hamiltonian;
- identical radial FE-DVR specifications on both centers initially;
- one conserved signed magnetic block, starting with `m = 0`;
- standard multicenter Becke weights specialized to two centers in the
  initial Hamiltonian;
- a separately represented Becke integration partition;
- Lebedev angular quadrature;
- dense overlap, kinetic, and potential matrices;
- generalized ground-state diagonalization;
- finite radial boxes with homogeneous radial boundary conditions;
- serial execution only.

The reusable foundation developed for that prototype must nevertheless:

- accept center positions with shape `(n_centers, 3)`;
- accept one charge and radial-grid specification per center;
- construct pairwise Becke switching functions for every `A != B`;
- support two and three collinear centers without changing the partition API;
- support noncollinear centers without changing the partition or quadrature
  API;
- keep fixed-`m` symmetry reduction optional rather than embedding it in the
  general basis representation;
- use one common global Cartesian orientation for all local spherical frames
  unless an explicit rotated-frame extension is added later.

The prototype does not initially include:

- real- or imaginary-time propagation;
- TDHF, TDKS, or TD-RASSCF;
- electron-electron mean fields;
- MPI or other distributed-memory parallelization;
- matrix-free Hamiltonian application;
- CAP or ECS;
- moving nuclei or a time-dependent basis;
- heteronuclear Becke radius corrections;
- a separate molecular outer grid.

## Mathematical representation

For the general multicenter representation, define

\[
\chi_{A k \ell m}(\mathbf r)
=
p_A(\mathbf r)
\frac{L_k^A(r_A)}{r_A}
Y_{\ell m}(\Omega_A),
\]

where `A` is an atomic center, `p_A` is an orbital-space partition function,
and `L_k^A` is an interface-matched FEM-DVR cardinal function with the radial
endpoint degrees of freedom removed. Local angular coordinates are measured
against axes parallel to one common global Cartesian frame. For a linear
geometry, choose the global `z` axis along the line of centers.

The basis is generally nonorthogonal. Assemble

\[
S_{\mu\nu}=\int \chi_\mu^*\chi_\nu\,d^3r,
\]

\[
T_{\mu\nu}
=
\frac{1}{2\mu_e}
\int \nabla\chi_\mu^*\cdot\nabla\chi_\nu\,d^3r,
\]

and

\[
V_{\mu\nu}
=
\int
\chi_\mu^*
\left(-\sum_C\frac{Z_C}{r_C}\right)
\chi_\nu\,d^3r.
\]

The electronic Hamiltonian is `H = T + V`, and stationary states satisfy

\[
H B = S B E.
\]

The kinetic matrix must be assembled in weak form. If

\[
\phi_A=\frac{L_k^A(r_A)}{r_A}Y_{\ell m}(\Omega_A),
\]

then

\[
\nabla(p_A\phi_A)=p_A\nabla\phi_A+\phi_A\nabla p_A.
\]

Same-center and cross-center matrix elements must contain all four products
generated by
`grad(p_A phi_A)^* dot grad(p_B phi_B)`. Applying the present one-center
radial second-derivative operator separately at each center is not a valid
substitute for the weak-form kinetic matrix.

## Geometry and angular symmetry

The Becke partition itself depends only on distances and therefore supports
arbitrary center positions. Angular symmetry reduction is a separate concern.

For any collinear geometry, choose the common global `z` axis along the line
of centers. The nuclear potential, Becke weights, and their gradients are
then independent of the global azimuthal angle. Signed `m` is conserved, so
the Hamiltonian may be assembled in independent fixed-`m` blocks. This
remains true for three or more collinear centers, including heteronuclear and
unequally spaced arrangements. Additional inversion or reflection reductions
are allowed only when the complete positions and charges possess those
symmetries.

For a generic noncollinear geometry there is no continuous axial symmetry.
The basis must retain the complete angular set

\[
-\ell\le m\le\ell,
\qquad
N_{\mathrm{ang}}=(\ell_{\max}+1)^2,
\]

and the matrices generally couple different `m` values. All centers should
still use parallel axes from a common global Cartesian frame. Center-specific
rotated axes are possible through Wigner rotations, but they are unnecessary
for the first generalization and complicate cross-center evaluation.

Introduce geometry metadata that validates the center array, rejects
coincident centers, and determines whether the centered position matrix has
rank one within a documented tolerance. For a collinear geometry, record a
unit molecular-axis vector and construct a deterministic right-handed global
frame with that vector as `z`. For a noncollinear geometry, retain the
supplied global Cartesian frame and require `full_lm` angular storage.
Symmetry classification must be diagnostic and testable; it must not silently
discard channels when a geometry is only approximately collinear.

## Orbital and integration partitions

The implementation must distinguish:

1. `p_A(r)`, included in the orbital basis functions;
2. `q_C(r)`, used to partition numerical integration.

The integration partition satisfies

\[
\sum_C q_C(\mathbf r)=1,
\]

and

\[
\int F(\mathbf r)\,d^3r
=
\sum_C\int q_C(\mathbf r)F(\mathbf r)\,d^3r.
\]

The prototype may use the same Becke construction for `p_A` and `q_A`, but
they must remain separate objects and separate factors. A matrix-element
integrand can therefore contain `q_C p_A p_B`.

The complete molecular nuclear potential must be used on every integration
partition. In particular,

\[
-\sum_A p_A(\mathbf r)\frac{Z_A}{r_A}
\]

is not the molecular Coulomb potential and must not be used.

## Proposed package layout

```text
grid_tdse/spherical/one_radial_becke/
├── __init__.py
├── geometry.py
├── specification.py
├── partition.py
├── quadrature.py
├── basis.py
├── assembly.py
├── metric.py
├── hamiltonian.py
└── ground_state.py
```

Responsibilities:

- `geometry.py`: center validation, rigid frames, collinearity metadata, and
  angular-channel mode selection;
- `specification.py`: immutable radial, angular, Lebedev, and Becke settings;
- `partition.py`: arbitrary-`N` pair switches, normalized weights, distances,
  unit vectors, and analytic gradients;
- `quadrature.py`: atom-centered Cartesian quadrature points and physical
  volume weights;
- `basis.py`: basis values and Cartesian gradients at arbitrary points;
- `assembly.py`: batched construction of `S`, `T`, and `V`;
- `metric.py`: overlap diagnostics, rank selection, and orthogonalization;
- `hamiltonian.py`: immutable assembled representation and diagnostics;
- `ground_state.py`: generalized eigensolver and result object.

The initial Hamiltonian should accept the existing
`OneElectronDiatomicSystem` through an adapter that exposes arrays of center
positions and charges. The lower-level partition, quadrature, and basis
objects should operate on those arrays directly and must not depend on a
diatomic system class. The new Hamiltonian should not subclass
`OneElectronDiatomicHamiltonian`, because its state metric and operator
representation are fundamentally different.

## Phase 0: freeze a reference problem

Define a reproducible reference calculation using the midpoint-centered
solver:

- H2+ with internuclear distance `R = 2` bohr;
- ground state in the `m = 0` block;
- a documented radial grid and radial box;
- a converged or systematically extrapolated reference energy;
- convergence data with respect to midpoint-centered `l_max` and radial
  polynomial order.

The prototype and reference solver must use identical physical parameters,
radial extent, and boundary conventions wherever a direct comparison is
possible.

### Phase 0 completion criterion

The reference input, energy, convergence table, and boundary conventions are
recorded in one test or development example and can be reproduced without
manual parameter changes.

## Phase 1: arbitrary-center Becke partition

Implement the partition for `N` distinct centers rather than first creating a
two-center-only class. For every ordered pair `A != B`, define

\[
\mu_{AB}(\mathbf r)
=
\frac{r_A-r_B}{R_{AB}},
\qquad
R_{AB}=|\mathbf R_A-\mathbf R_B|.
\]

After applying the iterated Becke switching polynomial `f`, define the pair
factor favoring center `A`, for example

\[
s_{AB}(\mathbf r)
=
\frac{1-f(\mu_{AB})}{2}.
\]

Construct unnormalized cell functions and normalized weights,

\[
P_A(\mathbf r)=\prod_{B\ne A}s_{AB}(\mathbf r),
\qquad
p_A(\mathbf r)=\frac{P_A(\mathbf r)}{\sum_C P_C(\mathbf r)}.
\]

The same general construction is used for the independently configured
integration weights `q_A`.

Provide vectorized evaluation of:

- center displacements with shape `(..., n_centers, 3)`;
- center distances and center-relative unit vectors;
- pair variables and switches for every `A != B`;
- unnormalized and normalized orbital and integration weights;
- analytic Cartesian gradients `grad p_A` and `grad q_A`.

Away from the nuclei,

\[
\nabla\mu_{AB}
=
\frac{\widehat{\mathbf r}_A-\widehat{\mathbf r}_B}{R_{AB}}.
\]

Differentiate the pair factors, products, and final normalization
analytically. Evaluate `grad P_A` with a direct product rule that remains
well-defined when a pair factor approaches zero; do not rely solely on
`P_A sum_B grad(s_AB)/s_AB`.

Required tests:

- `sum_A p_A = 1` for `N = 1`, `2`, and `3`;
- `sum_A grad p_A = 0` for the same geometries;
- `0 <= p_A <= 1` within roundoff;
- correct limiting values at every nucleus;
- analytic gradients against finite differences away from nuclei;
- invariance under permutation of center labels;
- covariance under rigid translation and rotation of all centers and points;
- agreement between scalar and vectorized evaluation;
- homonuclear exchange symmetry for two centers;
- three-center tests for both collinear and noncollinear positions.

Reject coincident centers explicitly because `R_AB = 0` makes the pair
construction undefined. Heteronuclear atomic-size corrections are deferred
until the uncorrected geometry-only partition is validated.

### Phase 1 completion criterion

One implementation and one API pass partition, gradient, permutation, and
rigid-motion tests for two-center, three-center collinear, and three-center
noncollinear geometries. No geometry-specific branches are needed except for
input validation and optional symmetry metadata.

## Phase 2: multicenter quadrature

For integration center `C`, radial node `r_j^C`, and Lebedev direction `n_q`,
construct

\[
\mathbf x_{Cjq}=\mathbf R_C+r_j^C\widehat{\mathbf n}_q.
\]

The physical volume weight is

\[
W_{Cjq}=w_j^{r,C}r_j^2w_q^\Omega q_C(\mathbf x_{Cjq}).
\]

Quadrature should be generated or consumed in radial-shell batches. A dense
array of all points is acceptable only for small tests.

Avoid evaluating the Coulomb potential exactly at any nucleus. A fixed
generic rotation of the Lebedev rule is a useful initial strategy because it
can prevent angular nodes from coinciding with any intercenter direction and
can avoid local spherical-coordinate poles. For arbitrary geometries, verify
this condition against every center pair rather than only one bond axis.

Required tests:

- partitioned integration of displaced Gaussians against analytic integrals;
- independent convergence with radial and Lebedev order;
- invariance of converged integrals under Lebedev-grid rotation;
- integration-partition exchange symmetry;
- agreement under permutation of three quadrature centers;
- collinear and noncollinear three-center partitioned integrals;
- finite-box error measured separately from quadrature errors.

Because finite atom-centered spheres do not cover identical domains, use
compact or rapidly decaying test functions and increase the radial extent
until the missing tail is negligible.

### Phase 2 completion criterion

Analytic Gaussian integrals converge predictably when radial order, Lebedev
order, and radial extent are refined independently.

## Phase 3: basis values and gradients

At arbitrary Cartesian points, evaluate

\[
\phi_{A k \ell m}
=
\frac{L_k^A(r_A)}{r_A}Y_{\ell m}(\Omega_A),
\]

its Cartesian gradient, and then

\[
\chi_{A k \ell m}=p_A\phi_{A k \ell m},
\]

\[
\nabla\chi_{A k \ell m}
=
p_A\nabla\phi_{A k \ell m}
+
\phi_{A k \ell m}\nabla p_A.
\]

`grid-lib` already provides `FEMDVR.interpolation_matrix(points)`. The
prototype also needs derivatives of the FEM-DVR cardinal basis at arbitrary
physical points. The preferred prerequisite is a tested
`FEMDVR.interpolation_derivative_matrix(points)` in `grid-lib`. If a cross-repo
change is undesirable for the initial experiment, use a private element-local
derivative evaluator temporarily and move it to `grid-lib` after validation.

Angular gradients must avoid unstable divisions at `sin(theta) = 0`. Use
stable Cartesian spherical-harmonic gradient identities or a rotated Lebedev
grid combined with analytic spherical derivatives. Cartesian finite
differences may be used in tests but not in matrix assembly.

The general basis evaluator must accept an explicit list of `(l, m)` channels
for each center. A collinear fixed-`m` basis supplies only channels with that
signed `m`; a noncollinear basis supplies every `m` for each retained `l`.
Basis evaluation must not infer axial symmetry from the number of centers.

Required tests:

- FEM-DVR interpolation is the identity at native radial nodes;
- radial cardinal derivatives reproduce representable polynomials;
- basis gradients agree with Cartesian finite differences away from
  singularities;
- local basis functions have the expected near-origin behavior;
- weighted basis functions have the correct nuclear limits;
- parallel local frames transform covariantly under a rigid rotation of the
  complete geometry;
- full-`(l, m)` evaluation works for a noncollinear three-center geometry;
- basis functions satisfy the radial outer boundary conditions.

### Phase 3 completion criterion

Values and Cartesian gradients of every basis-function family are validated
independently of matrix assembly.

## Phase 4: dense matrix assembly

For each quadrature batch, construct

\[
E_{q\mu}=\chi_\mu(\mathbf x_q),
\qquad
G^{(d)}_{q\mu}=\partial_d\chi_\mu(\mathbf x_q),
\]

along with physical weights `W_q` and the complete nuclear potential `V_q`.
Accumulate

\[
S \mathrel{+}=E^\dagger W E,
\]

\[
T \mathrel{+}=
\frac{1}{2\mu_e}
\sum_{d=x,y,z}G^{(d)\dagger}WG^{(d)},
\]

and

\[
V \mathrel{+}=E^\dagger W V_{\mathrm{nuc}}E.
\]

Use dense matrix multiplication per batch rather than Python loops over basis
pairs. The assembly API should accept an explicit angular channel table and
must not contain an unconditional fixed-`m` assumption. For the initial
collinear diatomic calculation, assemble the requested signed-`m` block
directly. For a future noncollinear calculation, assemble the full channel
table, including all cross-`m` matrix elements.

Every assembly result should report:

- relative anti-Hermitian norms of `S`, `T`, `V`, and `H`;
- minimum and maximum overlap eigenvalues;
- overlap condition number before truncation;
- same-center and cross-center block norms;
- geometry classification and the angular channel mode (`fixed_m` or
  `full_lm`);
- basis and quadrature sizes;
- all radial, angular, Becke, and cutoff parameters.

Large anti-Hermitian components must be treated as errors. Final
symmetrization is acceptable only for roundoff after diagnostics have passed.

### Phase 4 completion criterion

Small test matrices converge under quadrature refinement, are Hermitian to the
expected tolerance, and agree with direct high-order checks for selected
elements.

## Phase 5: overlap conditioning and diagonalization

Diagonalize

\[
S=U\operatorname{diag}(s)U^\dagger.
\]

Retain eigenvectors satisfying

\[
s_i>\tau s_{\max},
\]

and construct

\[
X=U_{\mathrm{retained}}s_{\mathrm{retained}}^{-1/2}.
\]

Solve

\[
X^\dagger H Xc=cE,
\qquad B=Xc.
\]

The result must include the overlap spectrum, cutoff `tau`, retained rank, and
discarded rank.

Required tests:

- `B^dagger S B = I`;
- small generalized residual `||H B - S B E||`;
- real eigenvalues within numerical tolerance;
- stable energies over a documented interval of overlap cutoffs;
- agreement with `scipy.linalg.eigh(H, S)` when `S` is well conditioned and
  full rank.

Initial cutoff studies should include at least `1e-8`, `1e-10`, and `1e-12`.

### Phase 5 completion criterion

The solver reports all rank decisions explicitly, returns normalized states,
and produces stable results for well-conditioned test problems.

## Phase 6: validation ladder

### 6.1 Single-center hydrogen limit

Set one orbital and integration partition to unity. Verify hydrogenic
energies, overlap normalization, kinetic positivity, and centered angular
selection rules.

### 6.2 Partitioned integration of the midpoint basis

Evaluate the existing midpoint-centered basis using Becke-Lebedev quadrature
and compare with its structured overlap, kinetic, and potential matrices. This
isolates quadrature and basis-evaluation errors before introducing the weighted
multicenter basis.

### 6.3 Two-center overlap

Assemble only `S` and study its spectrum as a function of internuclear
distance, radial extent, radial order and element layout, `l_max`, Lebedev
order, and Becke iteration count. This is the first major feasibility gate.

Implementation status: complete for the prototype. The validation path uses
an integration radius of `r_max + R` about each center. Thus every integration
cell covers the complete union of both finite atom-centered basis supports,
and a missing part of one partition cell cannot be mistaken for overlap rank
loss. The reproducible study varies one parameter family at a time and reports
the complete spectrum, condition number, and retained ranks at relative
cutoffs `1e-8`, `1e-10`, and `1e-12`.

For the baseline `R = 2`, radial nodes `(0, 2, 4)`, four Lobatto points per
element, `m = 0`, `l_max = 1`, Lebedev order 29, and three Becke smoothing
iterations, the 20-dimensional overlap is positive definite with a condition
number of approximately 16.6. Conditioning becomes worse for smaller
internuclear distance, larger radial extent, higher radial order, finer
element layouts, and larger angular cutoff. Increasing the Becke smoothing
order from one to four improves the condition number for this baseline.

The angular sweep exposes the first cutoff-relevant near-linear dependence.
At `l_max = 11` the 120-dimensional overlap has a condition number of about
`1.3e8`: cutoff `1e-8` retains 119 directions, while `1e-10` and `1e-12`
retain all 120. Lebedev orders 29 and 41 agree on this rank decision and on
the smallest eigenvalue to about one percent, so the observed loss is not an
obvious low-order angular-quadrature artifact. This is a warning rather than
a rejection of the representation: modest angular cutoffs remain comfortably
full rank, while Phases 6.5 and 6.6 must determine whether energies are stable
against the overlap cutoff before the feasibility decision is final.

### 6.4 Two-center kinetic energy

Assemble `T` and verify Hermiticity and positive semidefiniteness. Compare
selected elements with direct high-order integration where practical.

Implementation status: complete for the prototype. The kinetic-only
validation uses the positive weak form and the same full-support integration
domain as Phase 6.3: each atomic integration cell extends to `r_max + R`.
The refined integration grid retains a parent-basis-element map so duplicated
FEM boundaries use the correct one-sided radial derivative trace. At the
outer support boundary, the exterior derivative of the owning center's
compact radial basis is explicitly zero while basis functions on the other
center remain active.

For the Phase 6.3 baseline basis, the coarse, refined, and high-order kinetic
matrices are Hermitian to relative anti-Hermitian norms below `7e-17` and
have strictly positive minimum eigenvalues near `9.4e-2`. Relative to the
high-order result, refinement reduces the full-matrix Frobenius error from
approximately `6.1e-2` to `8.0e-3`. Selected same-center diagonal,
same-center off-diagonal, and cross-center elements agree with high-order
integration to relative errors between approximately `7e-6` and `1.6e-3`.
The validation also confirms the expected inverse scaling with particle mass.

These results validate the sign, weak-form construction, FEM trace handling,
and positive-semidefinite character of `T`. The remaining percent-level norm
difference is quadrature convergence rather than a positivity failure; the
independent radial and angular convergence studies remain part of Phase 6.6.

### 6.5 H2+ ground state

Assemble `H`, solve the generalized eigenproblem, and compare with the
midpoint-centered reference at the same geometry and boundary extent.

Implementation status: complete for the baseline prototype. The overlap,
weak kinetic, and complete two-nucleus Coulomb matrices are assembled on the
full-support integration domain from Phases 6.3 and 6.4. The generalized
eigenproblem is solved independently at relative overlap cutoffs `1e-8`,
`1e-10`, and `1e-12`, and the report includes metric ranks, normalization,
residuals, Hermiticity, and quadrature refinement.

For `R = 2`, atomic nodes `(0, 2, 4)`, four Lobatto points per element,
`l_max = 1`, and `m = 0`, the high-order integration gives the electronic
energy `-1.068260866069 Eh` and the clamped-nuclei total energy
`-0.568260866069 Eh`. All three overlap cutoffs retain all 20 basis
directions and give the same energy to displayed precision. The maximum
relative generalized residual is approximately `1.3e-15`, and the maximum
relative anti-Hermitian matrix norm is below `5e-17`.

Changing the integration from the deliberately coarse radial/Lebedev rule to
the refined rule reduces the energy difference from the high-order result
from approximately `1.0e-3 Eh` to `8.4e-6 Eh`. Thus the complete Hamiltonian
path is numerically consistent at the present basis size.

The midpoint comparison uses a centered sphere of radius
`r_max + R/2 = 5`, the smallest centered sphere containing both atomic
support spheres. It therefore matches the maximum physical reach of the
Becke basis but not the exact finite-domain shape. A midpoint calculation
with radial order 12 and `l_max = 10` gives electronic energy
`-1.101212970313 Eh`. The baseline Becke result is higher by approximately
`3.30e-2 Eh`. This is not a failure of the generalized solve or integration:
the baseline Becke basis deliberately contains only 20 functions and
`l_max = 1`. Phase 6.6 must determine how rapidly that difference closes
under independent radial, angular, and partition refinement.

### 6.6 Independent convergence studies

Vary one parameter family at a time:

- radial polynomial order;
- radial element boundaries;
- radial extent;
- Lebedev order;
- orbital `l_max`;
- Becke switching order;
- overlap cutoff.

Simultaneous changes in several parameters are not sufficient evidence of
convergence because they do not identify the dominant error.

Implementation status: complete for the prototype. The study caches matrix
assemblies and changes one parameter family at a time from the Phase 6.5
baseline. Except in the Lebedev sweep, integration uses maximum radial
subelement width 1, eight Lobatto points per integration element, and Lebedev
order 29. The orbital Becke-order sweep keeps the integration partition fixed
at three smoothing iterations, so it measures a representation change rather
than simultaneously changing integration coordinates. The radial-extent
sweep adds elements of the baseline width instead of stretching a fixed
number of elements.

A fixed, larger midpoint reference with atomic-equivalent radial extent 12,
radial order 15, and `l_max = 12` gives electronic energy
`-1.102136431141 Eh`. It is used as a common diagnostic reference for every
sweep rather than recomputing a different finite-box reference at each point.

The main findings are:

- radial order 3 through 6 lowers the Becke electronic energy from
  `-1.009171353462 Eh` to `-1.073888480866 Eh`; the last change remains about
  `1.2e-3 Eh`, so polynomial convergence is incomplete;
- refining the element layout at fixed extent lowers the energy, with a final
  change of approximately `1.5e-4 Eh`;
- increasing `r_max` from 6 to 8 changes the energy by approximately
  `3.0e-5 Eh`, indicating that box extent is close to stable for this basis;
- increasing Lebedev order from 29 to 41 changes the energy by approximately
  `1.1e-6 Eh`;
- increasing `l_max` from 3 to 4 changes the energy by approximately
  `7.7e-4 Eh`, while the overlap condition number grows from about `6.5e3`
  to `7.6e4`; angular-basis convergence is therefore also incomplete;
- changing the orbital Becke smoothing order from one to four changes both
  energy and conditioning appreciably at fixed finite basis. Higher smoothing
  improves the overlap condition number but does not monotonically improve
  the energy relative to the midpoint reference, so the iteration count is a
  genuine finite-representation parameter rather than a harmless quadrature
  choice;
- the baseline 20-dimensional basis is insensitive to cutoffs `1e-8` through
  `1e-12`. At `l_max = 11`, however, cutoff `1e-8` discards one of 120
  directions and raises the electronic energy by approximately `1.44e-4 Eh`;
  cutoffs `1e-10` and `1e-12` retain all directions and agree.

The representation remains feasible enough to continue to the cusp
diagnostic, but this phase does not yet establish the completed-prototype
accuracy target. Subsequent energy calculations should use overlap cutoff no
larger than `1e-10`, report retained rank, and refine radial order/layout
together with `l_max`. The rapid growth of the overlap condition number
remains the principal reason to reconsider an attenuated
atomic-plus-outer-patch representation for larger boxes or angular cutoffs.

### 6.7 Nuclear-cusp diagnostic

Reconstruct the orbital near each nucleus and test the spherical-average
electron-nuclear cusp behavior. Compare cusp and energy errors at equal
retained basis dimension, not only at equal `l_max`.

### 6.8 Three-center partition and quadrature validation

Before extending the Hamiltonian, exercise the general infrastructure with:

- three equally spaced collinear centers;
- three unequally spaced collinear centers;
- a bent three-center geometry;
- a generic scalene triangular geometry.

For each case, verify partition of unity, the zero gradient sum, permutation
invariance, rigid-translation invariance, rigid-rotation covariance, and
partitioned integration of displaced analytic test functions. For collinear
geometries, also verify azimuthal invariance of the weights. For noncollinear
geometries, verify that no fixed-`m` mode is selected.

## Follow-on three-center Hamiltonian milestones

Three-center Hamiltonians are not required to validate the first H2+
prototype, but the extension path should be explicit.

### Collinear three-center milestone

Add a one-electron, three-center collinear system using the same fixed-`m`
assembly path as the diatomic prototype. Validate:

- agreement between translated or rigidly rotated versions of the same
  geometry;
- permutation invariance under relabeling equivalent centers;
- preservation of the selected signed-`m` block;
- energy and overlap-spectrum convergence with radial order, Lebedev order,
  `l_max`, radial extent, and overlap cutoff;
- optional inversion reduction only for geometries and charges that actually
  possess inversion symmetry.

### Noncollinear three-center milestone

Add a one-electron bent or triangular system using `full_lm` storage. Validate:

- nonzero cross-`m` matrix elements where symmetry permits them;
- Hermiticity of the complete angular matrix;
- invariance of eigenvalues under rigid rotation of the complete system;
- covariance of eigenvectors within degenerate subspaces;
- convergence against independent radial and angular refinements.

This milestone should use parallel local axes inherited from one global
Cartesian frame. Locally rotated angular frames and Wigner transformations
remain a later optimization experiment.

## Scaling expectations

For center-dependent radial sizes and angular channel sets,

\[
N_{\mathrm{basis}}
=
\sum_A N_r^A N_{\mathrm{ang}}^A.
\]

For a collinear fixed-`m` calculation,

\[
N_{\mathrm{ang}}^A=\ell_{\max}^A-|m|+1,
\]

whereas a noncollinear full-`lm` calculation retains

\[
N_{\mathrm{ang}}^A=(\ell_{\max}^A+1)^2.
\]

The dense prototype therefore has approximately quadratic matrix storage,
quadratic assembly work per quadrature point, and cubic diagonalization cost
in `N_basis`. Losing fixed-`m` blocks is expected to be a larger cost increase
than adding a third center. Do not optimize this scaling until the two-center
and three-center overlap spectra establish that the representation is
numerically viable.

## Success criteria

The prototype is successful when it demonstrates:

- partition and gradient identities near machine precision;
- the same partition implementation passes two-center and three-center,
  collinear and noncollinear geometry tests;
- independent radial and angular quadrature convergence;
- a positive-semidefinite overlap matrix before rank truncation;
- `B^dagger S B = I` for retained orbitals;
- positive-semidefinite kinetic energy within quadrature tolerance;
- a Hermitian Hamiltonian within numerical tolerance;
- small generalized eigenproblem residuals;
- consistent H2+ energy convergence under independent refinement;
- energy stability over a defensible range of overlap cutoffs;
- target accuracy with a smaller angular cutoff or retained spatial dimension
  than the midpoint-centered representation.

A useful completed-prototype target is agreement with a converged H2+
reference to approximately `1e-6 Eh`, supported by convergence studies rather
than a single matching calculation.

## Principal risk and decision gate

Standard multicenter Becke weights do not localize the atomic expansions at
large distance. They approach direction-dependent values, so multiple atomic
bases retain support in the outer region. The resulting redundancy may cause
small overlap eigenvalues and increasing cutoff sensitivity as the radial box
and number of centers grow.

Examine the overlap spectrum before implementing performance optimizations or
nonlinear orbital equations. The two-center prototype is viable only if the
ground-state energy remains stable under reasonable changes of overlap cutoff
and radial extent.

If it is not stable, the next representation should introduce smoothly
attenuated atomic patches and a molecular outer patch,

\[
\sum_A p_A+p_{\mathrm{outer}}=1.
\]

The outer patch would also provide the natural location for later CAP or ECS
treatment. It should not be added to the first prototype unless the overlap
study shows that it is immediately necessary.

## Work deferred to `tdmcscf`

After validation, `tdmcscf` may consume a spatial interface providing:

- the overlap matrix;
- orbital evaluation at multicenter quadrature points;
- projection from quadrature values into the basis;
- weak one-body operator actions;
- density-to-potential Poisson or Coulomb operations;
- spatial inner products and orthonormalization support.

`tdmcscf` should own density matrices, Hartree and exchange construction,
exchange-correlation functionals, orbital projectors, RAS orbital rotations,
CI amplitudes, nonlinear propagation, and the constraint
`B^dagger S B = I` for propagated orbitals.

## Recommended implementation order

1. Freeze and document the midpoint-centered H2+ reference calculation.
2. Implement center-array validation, rigid frames, and collinearity metadata.
3. Implement arbitrary-`N` Becke weights and analytic gradients.
4. Validate the partition for two-center and three-center, collinear and
   noncollinear geometries.
5. Implement and validate multicenter radial-Lebedev quadrature for the same
   geometry set.
6. Add arbitrary-point FEM-DVR derivative interpolation.
7. Implement atom-centered basis values and Cartesian gradients with explicit
   angular channel tables.
8. Assemble and study the two-center overlap matrix before Hamiltonian work.
9. Implement the weak kinetic and complete nuclear-potential matrices for the
   collinear fixed-`m` H2+ prototype.
10. Add overlap conditioning and generalized diagonalization.
11. Complete independent convergence and cusp studies.
12. Decide whether the two-center basis is viable or needs an outer patch.
13. If viable, validate a collinear three-center fixed-`m` Hamiltonian.
14. Add a noncollinear three-center `full_lm` Hamiltonian only after the dense
    scaling and overlap conditioning are understood.

Performance optimization, matrix-free operation, MPI, continuum boundaries,
and the `tdmcscf` backend should begin only after this decision gate.
